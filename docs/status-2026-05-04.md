## 遗留问题

### 1. Citadel 连接复用不稳定
- 首次连接正常，切换主机或重复操作后报 `SFTP error 1`（SSH_FX_EOF）
- 疑似 NIO event loop 释放不充分，端口/资源冲突
- 已尝试：缓存连接、加延时、Task.detached vs Task、自定义算法
- **建议**：进一步调试 NIO 生命周期，或换用 libssh2 SFTP（已验证稳定）

### 2. 分屏关闭标签崩溃
- `FileTransferSplitPanel` 中使用 `@EnvironmentObject` 导致 View 销毁时 Swift 运行时崩溃
- 临时回退到单面板 `FileTransferPanel`
- 已改成传 `let` 参数但仍有其他问题

### 3. SSH Agent/Key 认证
- SFTP 只支持密码认证
- `loadRemoteDirectory` 检查 `case .password`，其他类型直接报错

### 4. 上传下载未充分测试
- 上传路径已实现但在切换会话时可能有问题
- 下载路径同样

### 5. 左侧面板拖放到右侧（上传）
- 拖放基础框架已搭，但只有右→左（下载）能工作
- 左→右（上传）需要跨面板通信

## 凭据存储架构

```
HostDefinition.authMode.password(ref: "password_xxx")
         ↓
CredentialResolver.password(for: ref, preference: .credentialStore)
         ↓
CredentialStore.shared.read(key: ref)
         ↓
AES-256-GCM 解密 credentials.enc → 返回密码
```
